# Nguyen Le Na — Portfolio clone

A standalone, responsive HTML/CSS/JS recreation based on the public text and section structure of the supplied portfolio website.

## Run locally
1. Unzip the package.
2. Open `index.html` in a browser, or run a local server:
   - `python3 -m http.server 8000`
   - visit `http://localhost:8000`

## Before publishing
- Add the real CV PDF at `assets/Nguyen_Le_Na_CV.pdf` (the download link is already wired to this path).
- Replace the LinkedIn URL in `index.html` with the exact profile URL.
- Verify dates, job titles and project descriptions before sharing externally.
- The mobile reporting UI and HRMS process visuals are illustrative portfolio graphics, not product screenshots.
- This package recreates the content and general visual direction from the accessible page text. It does not include the original website's source code, proprietary assets, or exact pixel measurements.

## Deploy
Upload the contents of this folder to any static hosting provider (Netlify, Vercel static hosting, GitHub Pages, or your own web server).
